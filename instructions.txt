The workflow designer is point-and-click, so not everything can be pasted as one block. But every value you'll need to type is below in a copyable box, in the order you'll need it.

## Option A: let Copilot build the workflow for you

When you create a new workflow, Copilot Studio usually offers a box to describe it. Paste this in, then check the result against Option B:

```
When an agent calls this flow, take a text input called "query". Make an HTTP GET request to https://www.ebi.ac.uk/europepmc/webservices/rest/search with query parameters query (the input), resultType=core, format=json and pageSize=10. From the response, use a Select action on resultList.result to keep only pmid, doi, title, journalTitle, pubYear, authorString and authorList. Respond to the agent with the Select output as text in an output called "results", and the response's hitCount as text in an output called "hitCount".
```

## Option B: build it step by step

**1. Create the workflow.** In your agent: **+ → Workflow → New workflow**. Name it:
```
Search Europe PMC
```

**2. Trigger: "When an agent calls the flow".** Add a **Text** input called:
```
query
```
with this description:
```
Europe PMC search query, e.g. AUTH:"Lemke JR" AND "angelman" AND PUB_YEAR:[2019 TO 2026]
```

**3. Add the action HTTP** (search for "HTTP" and choose the one simply called HTTP).
- **Method:** `GET`
- **URI:**
```
https://www.ebi.ac.uk/europepmc/webservices/rest/search
```
- **Queries:** add four rows.

| Key | Value |
|-|-|
| `query` | the trigger's **query** input (pick it from dynamic content, the lightning-bolt icon) |
| `resultType` | `core` |
| `format` | `json` |
| `pageSize` | `10` |

**4. Add the action "Select"** (Data Operation). This trims the response so the agent isn't swamped with abstracts.
- **From:** switch to the expression editor (fx) and paste:
```
body('HTTP')?['resultList']?['result']
```
- **Map:** switch to text mode (the small toggle beside Map) and paste:
```
{
  "pmid": "@{item()?['pmid']}",
  "doi": "@{item()?['doi']}",
  "title": "@{item()?['title']}",
  "journal": "@{item()?['journalTitle']}",
  "year": "@{item()?['pubYear']}",
  "authors": "@{item()?['authorString']}",
  "authorDetails": @{item()?['authorList']}
}
```

**5. Add the action "Respond to the agent".** Add two **Text** outputs:
- `results` with this expression:
```
string(body('Select'))
```
- `hitCount` with this expression:
```
string(body('HTTP')?['hitCount'])
```

**6. Save and publish** the workflow. If an action name doesn't match (for example the HTTP action is called "HTTP 1"), change `'HTTP'` or `'Select'` in the expressions to match.

## Add it to the agent

**7. Tool description.** When adding the workflow as a tool, use:
```
Searches Europe PMC, which includes all PubMed records, and returns up to 10 articles with PMID, DOI, title, journal, year, authors in order, and each author's affiliation. Use it to find publications by a named clinician or on a disease or drug. Query syntax: AUTH:"Surname Initials" for an author; AFF:"City or institution" for an affiliation; PUB_YEAR:[2019 TO 2026] for years; combine with AND / OR; put phrases in double quotes.
```

**8. Agent instructions** (for the test agent):
```
You help Medical Affairs check the publication record of clinicians. Always use the Search Europe PMC tool for publication questions; never answer from memory. For each paper report the PMID, year, journal, the clinician's author position (first, last, or position n of N, counted from authorDetails) and their affiliation as listed in authorDetails. If the tool returns nothing, say so. Cite PMIDs exactly as returned.
```

## Test it

**9. In the test pane, ask:**
```
Find Angelman syndrome papers by Johannes Lemke since 2019. For each, give the PMID, his author position and his affiliation.
```

**10. Check the answer.** Search PubMed in your browser for `Lemke JR[au] AND angelman`, and compare the PMIDs and affiliations.

## If something fails

- **Can't add the HTTP action, or a "policy" or "premium" message:** the tenant blocks it, and you'll need an admin (or the MCP route).
- **The HTTP action runs but returns an error status:** copy the status and error text back to me.
- **A timeout:** agent workflows must respond quickly (Microsoft's documented limit is about 100 seconds). Lower `pageSize` to 5.
- **The agent answers without calling the tool:** add "Always call Search Europe PMC first" to the top of the instructions.
